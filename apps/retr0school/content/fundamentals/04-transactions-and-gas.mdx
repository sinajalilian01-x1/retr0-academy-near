# Transactions and Gas

A **transaction** is a signed instruction that changes the state of the blockchain: sending ETH, transferring a token, or calling a smart contract function.

<Anim name="tx-flow" caption="From wallet signature to contract execution in about two seconds." />

## What is inside a transaction?

```json
{
  "from": "0xYourAddress...",
  "to": "0xRecipientOrContract...",
  "value": "0.01 ETH",
  "data": "0x (empty for a simple transfer, or encoded contract call)",
  "nonce": 42,
  "gasLimit": 21000,
  "maxFeePerGas": "30 gwei",
  "maxPriorityFeePerGas": "2 gwei",
  "chainId": 1
}
```

- **nonce**: a counter of how many transactions this address has sent. It keeps transactions in order and prevents the same one being replayed.
- **chainId**: which network this is for (1 = Ethereum mainnet, 11155111 = Sepolia testnet).
- **data**: for contract calls, the encoded function name and arguments.

## The life of a transaction

1. You create the transaction in your wallet and **sign** it with your private key.
2. The wallet **broadcasts** it to the network. It waits in a pool of pending transactions (the *mempool*).
3. A validator includes it in a new **block**.
4. The transaction is **confirmed**. As more blocks are added on top, it becomes final.

<Warning>
Confirmed transactions **cannot be undone**. There is no "cancel" or "chargeback". If you send to the wrong address, the funds are almost certainly gone. Always double-check the address and the network.
</Warning>

## What is gas?

Every operation on Ethereum (adding numbers, storing data, sending ETH) costs a certain amount of **gas**, a unit measuring computational work. Gas stops people from spamming the network or running infinite loops, and it pays validators for their work.

- A simple ETH transfer always uses **21,000 gas**.
- Contract calls use more, depending on how much work they do. Writing to storage is one of the most expensive operations.

## Gas price and the fee formula

Gas *amount* is fixed by the work. The *price* per unit of gas changes with demand. Prices are quoted in **gwei**:

```bash
1 gwei = 0.000000001 ETH   (one billionth of an ETH, 10^-9)
1 ETH  = 1,000,000,000 gwei
```

Since the London upgrade (EIP-1559), the fee works like this:

```bash
fee = gas used × (base fee + priority fee)
```

- **Base fee**: set automatically by the network based on how full recent blocks were. It is **burned** (destroyed).
- **Priority fee** (tip): an extra amount paid to the validator to include your transaction sooner.
- **Max fee**: the most you are willing to pay per gas. You never pay more than base fee + tip, and any difference is refunded.
- **Gas limit**: the maximum gas you allow the transaction to use. If it runs out, the transaction fails, but the gas already used is still charged.

## Failed transactions

A transaction can fail ("revert") if:

- It runs out of gas (gas limit too low).
- The contract's rules reject it (for example, not enough token balance).

When a transaction reverts, all its changes are undone, **but you still pay for the gas used**.

## Reading a block explorer

On Etherscan (or Sepolia Etherscan for the testnet), a transaction page shows:

- **Status**: Success, Failed, or Pending
- **Block** number and confirmations
- **From** and **To** addresses
- **Value** sent
- **Transaction fee** and **gas price**
- **Input data** (for contract calls)

Every transaction has a unique **transaction hash** (like `0x5c50...`) you can search for.

## Summary

- A transaction is a signed instruction with a sender, recipient, value, data, and nonce.
- Gas measures work; the fee is gas used × (base fee + priority fee).
- Prices are in gwei: one billionth of an ETH.
- Confirmed transactions are permanent, and failed ones still cost gas.

## Gas and storage on NEAR

NEAR charges for two different things.

## Gas: computation

Every transaction burns **gas**, measured in **Tgas** (10^12 gas). Gas has a price in NEAR set by the network, and it is low and stable. A simple contract call is a few Tgas, and one transaction can attach up to **300 Tgas**.

- Unused gas is refunded.
- 30% of the gas burned by a contract call is paid to that **contract's account**, so builders earn from usage.

## Storage: bytes on chain

State is not paid per transaction. Instead the account that **holds** the data must keep enough NEAR locked: about **1 NEAR per 100 KB** (10^19 yocto per byte). This is called **storage staking**. Delete the data and the NEAR unlocks again.

That is why many contracts ask you to attach a small **deposit**. The Retr0 Academy diploma contract does this: you attach 0.02 NEAR when you mint, the contract measures how many bytes your diploma used, keeps exactly that, and **refunds the rest** in the same call.

```rust
// from contracts/diploma/src/lib.rs
let token = self.tokens.internal_mint_with_refund(
    token_id, account_id.clone(), Some(metadata), Some(account_id),
);
```

<Tip>

Rule of thumb: view calls are free, change calls cost gas, and anything that adds state needs a storage deposit.

</Tip>

## Quick numbers

| Thing | Typical cost |
| --- | --- |
| Transfer NEAR | about 0.45 Tgas |
| Mint one diploma | under 20 Tgas, plus a storage deposit of about 0.01 NEAR |
| 100 KB of contract state | 1 NEAR locked |
