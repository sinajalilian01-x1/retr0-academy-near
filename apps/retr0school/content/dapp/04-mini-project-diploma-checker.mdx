# Mini Project: Diploma Checker

Build a small page that looks up any NEAR testnet account and shows whether it holds a Retr0 Academy diploma. This is a complete, useful dApp you can run entirely in the Playground with **view calls only**. After it works, you can optionally add NEAR Connect to sign in and deep-link to mint.

## What you will ship

1. An input for a testnet account id
2. A Verify button
3. A result panel: valid diploma (track, score, date) or a clear "no diploma yet"
4. A link to the public verify page `/verify?account=...`

## Starter (open this in the Playground and finish it)

The example below already performs the RPC call. Your job is to improve the UX: validate the account id, show a loading state, format the score, and handle errors without looking broken.

const SITE = "https://retr0school-near.vercel.app";

async function view(method, args) {
  const res = await fetch("https://rpc.testnet.near.org", {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({
      jsonrpc: "2.0", id: "r0", method: "query",
      params: {
        request_type: "call_function", finality: "final",
        account_id: CONTRACT, method_name: method,
        args_base64: btoa(JSON.stringify(args || {}))
      }
    })
  });
  const json = await res.json();
  if (json.error) throw new Error(JSON.stringify(json.error.cause || json.error));
  return JSON.parse(new TextDecoder().decode(new Uint8Array(json.result.result)));
}

document.getElementById("go").addEventListener("click", async () => {
  const account = document.getElementById("account").value.trim().toLowerCase();
  const out = document.getElementById("out");
  const link = document.getElementById("link");
  out.textContent = "Calling verify_diploma...";
  link.textContent = "";
  try {
    const diploma = await view("verify_diploma", { account_id: account, track: "near" });
    if (diploma) {
      out.textContent = "Valid diploma\\n" + diploma.track_title + "\\nScore " + diploma.score + "/" + diploma.max_score + "\\n" + diploma.date;
    } else {
      out.textContent = "No NEAR diploma for " + account + " yet.";
    }
    const a = document.createElement("a");
    a.href = SITE + "/verify?account=" + encodeURIComponent(account);
    a.target = "_blank";
    a.rel = "noopener";
    a.textContent = "Open the public verify page ↗";
    link.appendChild(a);
  } catch (e) {
    out.textContent = "Error: " + e.message;
  }
});`}

## Stretch goals

- Style a "holder" card when `valid` is true (score, date, token id if the view returns it)
- Reject obviously invalid ids before calling RPC (NEAR account ids are lowercase and contain a `.` or are 64-character implicit ids)
- Add a Connect button with NEAR Connect (previous lesson) and default the input to the signed-in account
- After a pass on the [diploma quiz](/near/quiz), mint from `/diploma` and check *your* account in this app

When the checker works in the Playground, use **Open in Code E** if you want a multi-file project to share.
