# Frontend dApp with near-api-js

A NEAR frontend does two jobs: **view** calls over RPC (free, no wallet) and **change** calls the user signs. The RPC library is [`near-api-js`](https://docs.near.org/tools/near-api). For wallets, [docs.near.org](https://docs.near.org/web3-apps/tutorials/wallet-login) now tells you **not** to start a new app on `@near-wallet-selector/*` — that stack is deprecated and unmaintained. Use [`@hot-labs/near-connect`](https://docs.near.org/tools/near-connect) instead.

This academy’s diploma button still uses Wallet Selector because it was built against that stack. New work should follow the official connector.

## Install and connect

```bash
npm install @hot-labs/near-connect near-api-js
```

```js
import { NearConnector } from "@hot-labs/near-connect";
import { JsonRpcProvider } from "near-api-js";

const connector = new NearConnector({ network: "testnet" });
const provider = new JsonRpcProvider({ url: "https://test.rpc.fastnear.com" });

// Connect (opens the wallet UI)
await connector.connect();
const wallet = await connector.wallet();
const accountId = await wallet.getAddress();
```

## View calls

NEAR Connect does not wrap view methods. Call the provider directly:

```js
const greeting = await provider.callFunction({
  contractId: "hello.near-examples.testnet",
  method: "get_greeting",
  args: {},
});
```

Plain `fetch` to `https://rpc.testnet.near.org` with `query` / `call_function` also works — that is what the Playground examples in these lessons use.

## Change calls

```js
const result = await wallet.signAndSendTransaction({
  receiverId: "hello.near-examples.testnet",
  actions: [
    {
      type: "FunctionCall",
      params: {
        methodName: "set_greeting",
        args: { greeting: "Hello from Retr0 Academy" },
        gas: "30000000000000", // 30 Tgas
        deposit: "0",
      },
    },
  ],
});
```

Attach a deposit as a yoctoNEAR string when the method is payable (`"10000000000000000000000"` is 0.01 NEAR). Budget 30–100 Tgas for simple calls; cross-contract work needs more.

## If you still see Wallet Selector

Older tutorials look like `setupWalletSelector({ network: "testnet", modules: [...] })` plus `setupModal`. That is the API this site uses for minting. Do not copy it into a new project. If you are maintaining an existing app, plan a move to NEAR Connect; the official “Your First Web3 App” guide already uses it with a function-call-key plugin for zero-deposit methods.
