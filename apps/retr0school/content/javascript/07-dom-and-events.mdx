# The DOM and Events

The **DOM** (Document Object Model) is the browser's live, tree-shaped representation of your HTML. JavaScript can read and change it, and the page updates instantly.

## Selecting elements

```js
document.getElementById("title");          // one element by id
document.querySelector(".card");           // the FIRST match of any CSS selector
document.querySelectorAll(".card");        // ALL matches (a NodeList)
document.querySelector("nav a.active");    // any CSS selector works
```

<Tip>
`querySelector` and `querySelectorAll` accept the same selectors you learned in CSS, so they are all you really need.
</Tip>

## Changing elements

```js
const title = document.querySelector("h1");

title.textContent = "New title";          // change text (safe)
title.style.color = "tomato";             // inline style
title.classList.add("highlight");         // add a CSS class
title.classList.remove("hidden");
title.classList.toggle("dark");           // add if missing, remove if present
title.setAttribute("data-step", "2");

const link = document.querySelector("a");
link.href = "https://developer.mozilla.org";
```

<Warning>
Avoid putting user input into `innerHTML`. If someone types HTML or a script, it would run on your page (a security hole called **XSS**). Use `textContent` for text, and create elements with `document.createElement`.
</Warning>

## Creating and removing elements

```js
const li = document.createElement("li");
li.textContent = "Learn the DOM";
document.querySelector("ul").appendChild(li);

li.remove(); // delete it again
```

## Events

An **event** is something that happens: a click, a key press, a form submission, the page loading. Listen for events with `addEventListener`:

```js
const button = document.querySelector("#save");

button.addEventListener("click", (event) => {
  console.log("Clicked!", event.target);
});
```

Common events:

| Event | Fires when |
| --- | --- |
| `click` | An element is clicked or tapped |
| `input` | The value of an input changes (every keystroke) |
| `change` | A select, checkbox, or input value is committed |
| `submit` | A form is submitted |
| `keydown` | A key is pressed |
| `mouseover` / `mouseout` | The pointer enters or leaves an element |
| `DOMContentLoaded` | The HTML has finished loading |

### Stopping default behavior

Forms reload the page when submitted. Stop that with `event.preventDefault()`:

```js
form.addEventListener("submit", (event) => {
  event.preventDefault();
  // handle the data with JavaScript instead
});
```

### Event delegation

Instead of adding a listener to every list item, add one to the parent and check `event.target`. It also works for items added later:

```js
list.addEventListener("click", (event) => {
  if (event.target.matches("button.delete")) {
    event.target.closest("li").remove();
  }
});
```

## Project: a to-do app

This app uses everything so far: variables, functions, arrays, objects, the DOM, and events. It even saves your tasks in `localStorage` so they survive a page reload.

  <h2>My To-Do List</h2>
  <form id="form">
    <input id="task" placeholder="What do you need to do?" autocomplete="off" required>
    <button type="submit">Add</button>
  </form>
  <ul id="list"></ul>
  <p id="count"></p>
</div>`} css={`body { font-family: system-ui, sans-serif; background: #fffbe6; }
.app { max-width: 360px; margin: 0 auto; }
form { display: flex; gap: 8px; }

button { padding: 8px 12px; border: 0; border-radius: 8px; background: #222; color: #F7DF1E; cursor: pointer; }
ul { list-style: none; padding: 0; }
li { display: flex; align-items: center; gap: 8px; padding: 8px; margin: 6px 0; background: white; border-radius: 8px; box-shadow: 0 1px 4px rgb(0 0 0 / 10%); }
li span { flex: 1; cursor: pointer; }
li.done span { text-decoration: line-through; color: #999; }
.delete { background: #e11d48; color: white; padding: 4px 8px; }`} js={`const form = document.getElementById("form");
const input = document.getElementById("task");
const list = document.getElementById("list");
const count = document.getElementById("count");

let todos = [];
try {
  todos = JSON.parse(localStorage.getItem("todos")) || [];
} catch (e) {
  todos = [];
}

function save() {
  try { localStorage.setItem("todos", JSON.stringify(todos)); } catch (e) {}
}

function render() {
  list.innerHTML = "";
  todos.forEach((todo, index) => {
    const li = document.createElement("li");
    if (todo.done) li.classList.add("done");
    li.dataset.index = index;

    const text = document.createElement("span");
    text.textContent = todo.text;

    const del = document.createElement("button");
    del.textContent = "✕";
    del.className = "delete";
    del.setAttribute("aria-label", "Delete " + todo.text);

    li.append(text, del);
    list.appendChild(li);
  });
  const left = todos.filter((t) => !t.done).length;
  count.textContent = left + " task(s) left";
}

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const text = input.value.trim();
  if (!text) return;
  todos.push({ text: text, done: false });
  input.value = "";
  save();
  render();
});

list.addEventListener("click", (event) => {
  const li = event.target.closest("li");
  if (!li) return;
  const index = Number(li.dataset.index);
  if (event.target.matches(".delete")) {
    todos.splice(index, 1);
  } else {
    todos[index].done = !todos[index].done;
  }
  save();
  render();
});

render();`} />

Click a task to mark it done; click ✕ to delete it.

## Summary

- `querySelector` and `querySelectorAll` find elements using CSS selectors.
- Change text with `textContent`, classes with `classList`, and attributes with `setAttribute`.
- Create elements with `createElement` and add them with `appendChild` or `append`.
- React to events with `addEventListener`; use `preventDefault` to stop default behavior.
