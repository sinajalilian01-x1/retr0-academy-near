# Functions

A **function** is a reusable block of code. Write it once, then call it as many times as you like.

## Declaring and calling

```js
function greet(name) {
  return "Hello, " + name + "!";
}

greet("Ada");    // "Hello, Ada!"
greet("Grace");  // "Hello, Grace!"
```

- `name` is a **parameter**: a placeholder for input.
- `"Ada"` is an **argument**: the actual value passed in.
- `return` sends a value back and ends the function.

<Note>
A function without a `return` statement returns `undefined`.
</Note>

## Default parameters

```js
function greet(name = "friend") {
  return "Hello, " + name + "!";
}
greet(); // "Hello, friend!"
```

## Function expressions and arrow functions

Functions are values, so you can store them in variables:

```js
// Function expression
const square = function (n) {
  return n * n;
};

// Arrow function: shorter syntax
const cube = (n) => {
  return n * n * n;
};

// Arrow with a single expression: return is implied
const double = (n) => n * 2;

double(21); // 42
```

## Scope

Variables declared inside a function (or any block with curly braces) only exist inside it. This is called **scope**.

```js
const site = "Retr0school";   // global: visible everywhere

function showLesson() {
  const lesson = "Functions";   // local: only inside showLesson
  console.log(site, lesson);    // works
}

showLesson();
// console.log(lesson);  // ❌ ReferenceError: lesson is not defined
```

<Tip>
Keep variables in the smallest scope that works. Fewer global variables means fewer accidental clashes and bugs.
</Tip>

## Functions as arguments (callbacks)

You can pass a function into another function. The passed function is called a **callback**:

```js
function repeat(times, action) {
  for (let i = 0; i < times; i++) {
    action(i);
  }
}

repeat(3, (i) => console.log("Round", i + 1));
```

You already used a callback: `button.addEventListener("click", function () { ... })`.

## Summary

- Define functions with `function name(params) { }` or arrow syntax `(params) => ...`.
- `return` sends a value back to the caller.
- Parameters can have defaults.
- Variables are scoped to the block or function where they are declared.
- Functions can be passed to other functions as callbacks.
