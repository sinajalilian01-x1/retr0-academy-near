# Deploying to Testnet

Testnet uses play NEAR from a faucet. Nothing here costs real money. Official tooling is [`cargo-near`](https://docs.near.org/smart-contracts/quickstart) to build and [`near-cli-rs`](https://docs.near.org/tools/cli) (the `near` binary) to create accounts and deploy. The older Node `near-cli` package is not what current docs recommend.

## Install

```bash
# Wasm target for Rust contracts
rustup target add wasm32-unknown-unknown

# cargo-near (build)
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/near/cargo-near/releases/latest/download/cargo-near-installer.sh | sh

# near-cli-rs (the `near` command)
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/near/near-cli-rs/releases/latest/download/near-cli-rs-installer.sh | sh
# or: npm install -g near-cli-rs@latest
```

`near` defaults to **testnet**. Use `--networkId testnet` anyway so the command is explicit.

## Build, create, deploy

```bash
cargo near build non-reproducible-wasm
# Wasm lands in ./target/near/<crate>.wasm

CONTRACT_ID=hello-r0.yourname.testnet
near create-account "$CONTRACT_ID" --useFaucet --networkId testnet

near deploy "$CONTRACT_ID" ./target/near/hello_near.wasm --networkId testnet
```

`--useFaucet` sponsors the new account on testnet. If the contract has an `#[init]` method and no `Default`, initialize in the same transaction (full `near contract deploy ... with-init-call` form in the [quickstart](https://docs.near.org/smart-contracts/quickstart)) or call it right after:

```bash
near call "$CONTRACT_ID" new '{"owner":"yourname.testnet"}' \
  --useAccount "$CONTRACT_ID" --networkId testnet
```

You can also build and deploy in one step: `cargo near deploy build-non-reproducible-wasm "$CONTRACT_ID"`.

## Call it

```bash
# Free read
near view "$CONTRACT_ID" get_greeting '{}' --networkId testnet

# Paid write, signed by your account
near call "$CONTRACT_ID" set_greeting '{"greeting":"Howdy"}' \
  --useAccount yourname.testnet --networkId testnet

# Payable method
near call "$CONTRACT_ID" donate '{}' \
  --deposit 0.01 --useAccount yourname.testnet --networkId testnet
```

Redeploying to the same account keeps the state and replaces the Wasm. If you changed the state layout, add a migration method or use a fresh account. Mainnet is the same commands with `--networkId mainnet` and real NEAR — do not use the faucet there.
