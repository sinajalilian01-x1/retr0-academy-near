# CSS Grid

Flexbox handles one direction at a time. **CSS Grid** handles **rows and columns together**, which makes it perfect for whole page layouts, galleries, and dashboards.

<Anim name="css-grid" caption="Grid places items on tracks; spans stretch across them." />

## Define a grid

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: auto 300px;
  gap: 16px;
}
```

- `grid-template-columns` defines the columns. Here: one 200px column and two flexible ones.
- `fr` means "fraction of the remaining space". `1fr 2fr` gives the second column twice as much as the first.
- `gap` sets the space between rows and columns.

## repeat() and minmax()

```css
grid-template-columns: repeat(3, 1fr);          /* three equal columns */
grid-template-columns: repeat(4, minmax(150px, 1fr));
```

### The responsive card grid

This one line creates a grid that fits as many columns as possible, each at least 180px wide, with no media queries:

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 16px;
}
```

## Placing items

Grid lines are numbered starting at 1. Items can span across lines:

```css
.featured {
  grid-column: 1 / 3;     /* from line 1 to line 3: spans 2 columns */
  grid-row: span 2;       /* spans 2 rows */
}
.full-width { grid-column: 1 / -1; } /* -1 means the last line */
```

## Named areas

`grid-template-areas` lets you draw your layout with words:

## Alignment in Grid

```css
.grid {
  justify-items: center;  /* horizontal alignment inside each cell */
  align-items: center;    /* vertical alignment inside each cell */
  place-items: center;    /* shorthand for both */
}
```

<Tip>
Grid or Flexbox? Use **Grid** when you think in rows *and* columns (page layout, galleries). Use **Flexbox** when you think in a single line of items (navbars, toolbars). They work great together: a grid of cards, with Flexbox inside each card.
</Tip>

## Summary

- `display: grid` with `grid-template-columns` and `grid-template-rows` defines the grid.
- `fr`, `repeat()`, and `minmax()` make flexible tracks.
- `repeat(auto-fit, minmax(...))` creates responsive grids with no media queries.
- Place items with line numbers or named `grid-template-areas`.
