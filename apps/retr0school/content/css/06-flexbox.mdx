# Flexbox

**Flexbox** is a one-dimensional layout system: it arranges items in a **row** or a **column**, and makes aligning and spacing them easy. Navbars, button groups, cards in a row, and perfectly centered content are all classic Flexbox jobs.

<Anim name="flexbox" caption="The same three items under different justify-content values." />

## Turn it on

```css
.container {
  display: flex;
}
```

The element with `display: flex` is the **flex container**; its direct children become **flex items**.

## The two axes

- The **main axis** follows `flex-direction` (horizontal for `row`, the default).
- The **cross axis** runs perpendicular to it.

```css
.container {
  flex-direction: row;       /* row | row-reverse | column | column-reverse */
  justify-content: center;   /* alignment on the main axis */
  align-items: center;       /* alignment on the cross axis */
  gap: 16px;                 /* space between items */
  flex-wrap: wrap;           /* allow items to wrap onto new lines */
}
```

### justify-content values

`flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly`

### align-items values

`stretch` (default), `flex-start`, `center`, `flex-end`, `baseline`

## Perfect centering

The famous "how do I center a div?" question has a two-line answer:

```css
.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

## Growing and shrinking items

Flex items have three properties that control their size:

```css
.item {
  flex-grow: 1;     /* how much of the extra space this item takes */
  flex-shrink: 1;   /* how much it shrinks when space is tight */
  flex-basis: 200px;/* its starting size before growing or shrinking */
}

/* Shorthand: grow shrink basis */
.item { flex: 1 1 200px; }
.sidebar { flex: 0 0 250px; } /* fixed 250px, never grows or shrinks */
.content { flex: 1; }         /* takes all remaining space */
```

<Tip>
`margin-right: auto` on a flex item pushes everything after it to the far end. It is a handy trick for navbars.
</Tip>

## Item-level alignment and order

```css
.special { align-self: flex-end; } /* override align-items for one item */
.first   { order: -1; }            /* visually move an item first */
```

<Warning>
`order` changes only the visual order. Keyboard and screen reader users still follow the HTML order, so do not use it to reorder meaningful content.
</Warning>

## Summary

- `display: flex` creates a flex container; its children become flex items.
- `justify-content` aligns on the main axis, `align-items` on the cross axis.
- `gap` adds space between items; `flex-wrap: wrap` allows wrapping.
- `flex: grow shrink basis` controls how items share space.
