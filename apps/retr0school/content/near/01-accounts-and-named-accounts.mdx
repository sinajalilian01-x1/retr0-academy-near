# Accounts and Named Accounts

On most chains your "account" is a long hex address derived from a key. On NEAR the account is a **name**. `alice.near` is not an alias that points somewhere else; it *is* the account, and it holds a balance, a set of keys, and optionally one smart contract.

## Kinds of accounts

| Kind | Example | Notes |
| --- | --- | --- |
| Top-level named | `alice.near`, `alice.testnet` | Created through the `near` or `testnet` registrar. |
| Sub-account | `diploma.retr0school.testnet` | Only `retr0school.testnet` can create it. Great for organizing apps. |
| Implicit | `98793cd9…a8f` (64 hex chars) | Derived from a public key. Exists as soon as it receives NEAR. |
| ETH-implicit | `0x…` | Lets Ethereum wallets use NEAR directly. |

This course runs on **testnet**, so accounts end in `.testnet`. The diploma contract you will mint from lives at `diploma.retr0school.testnet`, a sub-account of `retr0school.testnet`.

<Note>

An account can have **many keys** and keys can be rotated. Your identity is the name, not a single private key. That is a big usability win over key-derived addresses.

</Note>

## Read an account

Every account's balance and storage use are public. Run the example, then try your own testnet account.

  js={`const RPC = "https://rpc.testnet.near.org";
const out = document.getElementById("out");

async function lookup(accountId) {
  const res = await fetch(RPC, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({
      jsonrpc: "2.0", id: "r0", method: "query",
      params: { request_type: "view_account", finality: "final", account_id: accountId }
    })
  });
  const json = await res.json();
  if (json.error) throw new Error(json.error.cause ? json.error.cause.name : json.error.message);
  return json.result;
}

document.getElementById("go").addEventListener("click", async () => {
  const id = document.getElementById("acc").value.trim();
  out.textContent = "Loading " + id + "...";
  try {
    const a = await lookup(id);
    const near = Number(BigInt(a.amount) / 10n ** 20n) / 10000;
    out.textContent = id + "\\nbalance: " + near + " NEAR\\nstorage used: " + a.storage_usage + " bytes\\nhas contract: " + (a.code_hash !== "11111111111111111111111111111111");
    console.log("account", a);
  } catch (e) {
    out.textContent = "Error: " + e.message;
  }
});`}

## Units

NEAR has 24 decimals. The smallest unit is the **yoctoNEAR**: 1 NEAR = 10^24 yocto. RPC responses return balances as strings in yocto, which is why the example uses `BigInt`.
