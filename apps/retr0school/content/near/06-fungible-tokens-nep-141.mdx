# Fungible Tokens (NEP-141)

**NEP-141** is NEAR's fungible token standard, like ERC-20 on Ethereum. USDC, wrapped NEAR (`wrap.near`), and most DeFi tokens on NEAR implement it.

## The core methods

| Method | Kind | What it does |
| --- | --- | --- |
| `ft_balance_of(account_id)` | view | Balance as a string in the token's smallest unit. |
| `ft_total_supply()` | view | Total supply. |
| `ft_metadata()` | view | Name, symbol, decimals, icon (NEP-148). |
| `ft_transfer(receiver_id, amount, memo)` | change | Moves tokens. Needs exactly 1 yoctoNEAR attached. |
| `ft_transfer_call(receiver_id, amount, msg)` | change | Transfers and then calls `ft_on_transfer` on the receiver, so one transaction can "pay a contract". |

<Note>

The **1 yoctoNEAR** deposit is a security trick: function-call keys cannot attach deposits, so a transfer always needs a full-access key, which means a real wallet confirmation.

</Note>

## Storage registration (NEP-145)

A token contract stores a balance for every holder, so a new holder must first pay for their row with `storage_deposit`. Wallets usually do this for you.

  js={`const RPC = "https://rpc.testnet.near.org";

// Read-only call: no wallet, no gas, no signature.
async function view(contractId, method, args) {
  const res = await fetch(RPC, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({
      jsonrpc: "2.0", id: "r0", method: "query",
      params: {
        request_type: "call_function", finality: "final",
        account_id: contractId, method_name: method,
        args_base64: btoa(JSON.stringify(args || {}))
      }
    })
  });
  const json = await res.json();
  if (json.error) throw new Error(JSON.stringify(json.error.cause || json.error));
  return JSON.parse(new TextDecoder().decode(new Uint8Array(json.result.result)));
}

const out = document.getElementById("out");
document.getElementById("go").addEventListener("click", async () => {
  const ft = document.getElementById("ft").value.trim();
  try {
    const meta = await view(ft, "ft_metadata", {});
    const supply = await view(ft, "ft_total_supply", {});
    out.textContent = meta.name + " (" + meta.symbol + ")\\ndecimals: " + meta.decimals + "\\ntotal supply (raw): " + supply;
  } catch (e) {
    out.textContent = "Error: " + e.message;
  }
});`}
