# View vs Change Calls

A NEAR contract exposes two kinds of methods.

| | View call | Change call |
| --- | --- | --- |
| Changes state? | No | Yes |
| Needs a signature? | No | Yes, a transaction |
| Costs gas? | No | Yes |
| How | RPC `query` with `call_function` | Wallet `signAndSendTransaction` |

## A view call over plain fetch

You do not need any library to read a contract. The RPC accepts JSON, and arguments are JSON encoded as base64. This example reads the **live Retr0school diploma contract** on testnet and checks whether an account holds a diploma.

  js={`const RPC = "https://rpc.testnet.near.org";

// Read-only call: no wallet, no gas, no signature.
async function view(contractId, method, args) {
  const res = await fetch(RPC, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({
      jsonrpc: "2.0", id: "r0", method: "query",
      params: {
        request_type: "call_function", finality: "final",
        account_id: contractId, method_name: method,
        args_base64: btoa(JSON.stringify(args || {}))
      }
    })
  });
  const json = await res.json();
  if (json.error) throw new Error(JSON.stringify(json.error.cause || json.error));
  return JSON.parse(new TextDecoder().decode(new Uint8Array(json.result.result)));
}

const out = document.getElementById("out");
document.getElementById("go").addEventListener("click", async () => {
  const account_id = document.getElementById("acc").value.trim();
  out.textContent = "Calling verify_diploma...";
  try {
    const v = await view("diploma.retr0school.testnet", "verify_diploma", { account_id, track: "near" });
    out.textContent = v ? JSON.stringify(v, null, 2) : "No diploma for " + account_id + " yet.";
  } catch (e) {
    out.textContent = "Error: " + e.message;
  }
});`}
/>

## A change call needs a wallet

To **write**, a wallet signs a transaction. With Wallet Selector (next lesson) it looks like this:

```js
import { actionCreators } from "@near-wallet-selector/core";

const wallet = await selector.wallet();
await wallet.signAndSendTransaction({
  receiverId: "diploma.retr0school.testnet",
  actions: [
    actionCreators.functionCall(
      "mint_diploma",
      { track: "near", answers: myQuizAnswers }, // e.g. [0, 2, 1, ...]
      100_000_000_000_000n,        // 100 Tgas
      20_000_000_000_000_000_000n, // 0.02 NEAR storage deposit
    ),
  ],
});
```

<Note>

The contract grades `answers` itself, so the score inside your diploma cannot be faked by the website. This is exactly the call the [diploma page](/diploma) makes after you pass the quiz.

</Note>
