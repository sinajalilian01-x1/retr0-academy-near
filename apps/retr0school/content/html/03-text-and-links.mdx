# Text Formatting and Links

## Meaningful text tags

HTML has tags that give text *meaning*, not just a look:

| Tag | Meaning | Usually displayed as |
| --- | --- | --- |
| `<strong>` | Strong importance | **Bold** |
| `<em>` | Emphasis (stress) | *Italic* |
| `<mark>` | Highlighted / relevant | Yellow background |
| `<code>` | A piece of code | Monospace font |
| `<small>` | Side comments, fine print | Smaller text |
| `<del>` / `<ins>` | Deleted / inserted text | Strikethrough / underline |
| `<sub>` / `<sup>` | Subscript / superscript | H₂O, x² |
| `<blockquote>` | A long quotation | Indented block |

<Note>
You may also see `<b>` and `<i>`. They make text bold or italic without adding importance. Screen readers can use `<strong>` and `<em>` to change tone, so prefer them when the meaning matters.
</Note>

## Links

Links are what make the web a *web*. You create one with the **anchor** element, `<a>`, and its `href` attribute (hypertext reference):

```html
<a href="https://developer.mozilla.org">Read the MDN docs</a>
```

### Absolute vs. relative URLs

```html
<!-- Absolute: a full address to another site -->
<a href="https://example.com/about">About Example</a>

<!-- Relative: a file on your own site -->
<a href="about.html">About us</a>
<a href="blog/first-post.html">My first post</a>
<a href="../index.html">Back up one folder</a>
```

### Opening in a new tab

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Opens in a new tab
</a>
```

<Tip>
Add `rel="noopener noreferrer"` when using `target="_blank"` on links to other sites. It stops the new page from controlling your page through JavaScript.
</Tip>

### Jumping within a page

Give an element an `id`, then link to it with `#`:

```html
<a href="#contact">Jump to contact</a>

<!-- ...lots of content... -->

<h2 id="contact">Contact</h2>
```

### Email and phone links

```html
<a href="mailto:hello@example.com">Email us</a>
<a href="tel:+15551234567">Call us</a>
```

<Warning>
Write link text that makes sense on its own. "Download the course syllabus" is far better than "click here", both for people using screen readers and for search engines.
</Warning>

## Summary

- Use `<strong>`, `<em>`, `<mark>`, and friends to give text meaning.
- Create links with `<a href="...">`.
- Use relative URLs for your own pages and absolute URLs for other sites.
- Use `#id` to jump to a section on the same page.
