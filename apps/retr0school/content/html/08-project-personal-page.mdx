## HTML entities

Some characters have special meaning in HTML, so you write them as **entities**:

| Character | Entity |
| --- | --- |
| `<` | `&lt;` |
| `>` | `&gt;` |
| `&` | `&amp;` |
| `"` | `&quot;` |
| © | `&copy;` |
| non-breaking space | `&nbsp;` |

## Accessibility checklist

Accessibility (often written **a11y**) means everyone can use your page, including people using screen readers, keyboards, or zoom.

- Every image has a meaningful `alt` (or `alt=""` if decorative).
- Headings follow a logical order, with one `<h1>`.
- Every form control has a `<label>`.
- Link text describes where it goes.
- You can reach and use everything with only the **Tab** and **Enter** keys.
- The page has `lang` on the `<html>` element.
- Use real `<button>` elements for actions and `<a>` for navigation.

<Warning>
Do not make a clickable `<div>`. It cannot be focused with the keyboard and screen readers do not announce it as a button. Use `<button>` instead.
</Warning>

## Validate your HTML

Paste your code into the free W3C Markup Validator (validator.w3.org) to catch missing tags, typos, and invalid nesting.
